# やること

思いついた瞬間に追加できる、シンプルなToDo。iPhoneのホーム画面に追加して使うWebアプリ（PWA）です。

公開URL: https://al26068.github.io/quick-todo/

## ver 3.1

- 背景を変えられる（プリセット6種、または自分の写真）。ヘッダーの画像ボタンから。端末ごとの設定です

## ver 3.0 — どの端末でも同じデータ

iPhone・iPad・PCのどこで開いても、同じ付箋が見えます。

- 1台目で「同期を始める」→ 表示される **同期コード** を、2台目以降の「同期に参加する」に貼り付けるだけ
- 追加・移動・メモ・アラーム・削除が、数秒〜45秒で他の端末に反映（付箋ごとに、あとから編集したほうを採用）
- オフラインでも編集でき、つながったときに自動で同期
- アラームの通知は、同期しているすべての端末に届く
- いまある付箋は消えず、同期にそのまま引き継がれる
- 同期コードは合鍵です。知っている人は付箋を見られるので、人に渡さないでください

同期と通知には、自分のサーバー（Cloudflare Workers、無料枠で動作）が必要です。`cd server && npm install && npm run setup` で作れます。詳しくは [server/README.md](server/README.md)。
サーバーがなくても、1台の中で使うぶんには ver 2.0 と同じように動きます。

## ver 2.0

- 付箋を **未着手・実行中・完了** の3つの領域で管理
- ボタン1つ、またはドラッグ&ドロップで付箋を別の領域へ移動（PCのマウスは付箋のどこを掴んでもOK、スマホは右端の ⠿）
- 段階ごとに記述式のメモ、未着手・実行中にはアラーム
- ver 1.x のデータは、すべて「未着手」に引き継がれる

## 構成

| --- | --- |
| `index.html` | アプリ本体（画面・データ・アラーム） |
| `sw.js` | オフライン対応と、通知の受信 |
| `config.js` | サーバーのURL（アプリ内の設定からも入力可） |
| `server/` | 同期・通知サーバー（Cloudflare Workers + D1） |
