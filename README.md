# やること

思いついた瞬間に追加できる、シンプルなToDo。iPhoneのホーム画面に追加して使うWebアプリ（PWA）です。

公開URL: https://al26068.github.io/quick-todo/

## ver 2.0

- 付箋を **未着手・実行中・完了** の3つの領域で管理
- ボタン1つ、またはドラッグ&ドロップで付箋を別の領域へ移動（PCのマウスは付箋のどこを掴んでもOK、スマホは右端の ⠿）
- 段階ごとに記述式のメモを残せる（未着手のメモ、実行中のメモ、完了のメモ）
- 未着手・実行中の付箋にアラームを設定して、時間になったら通知
- ver 1.x のデータは、すべて「未着手」に引き継がれる（旧データは消さずに残す）

アプリを閉じている間も通知するには、`server/` の通知サーバーが必要です。手順は [server/README.md](server/README.md) にあります。
サーバーがなくても、アプリを開いている間はアラームが通知されます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（画面・データ・アラーム） |
| `sw.js` | オフライン対応と、通知の受信 |
| `config.js` | 通知サーバーのURL（アプリ内のベルからも設定可） |
| `server/` | 通知サーバー（Cloudflare Workers + D1） |
